# Deployment Gate

- [ ] Correct branch/commit/project.
- [ ] Frozen install, lint/typecheck and production build pass.
- [ ] Environment variables exist by name and environment; values not printed.
- [ ] Domain, HTTPS, Auth, database and Rules verified.
- [ ] SPA fallback, static assets, robots/sitemap and direct URLs tested.
- [ ] Error handling, monitoring and costs have owners.
- [ ] Mobile/desktop smoke passed.
- [ ] Rollback command/deployment is known.
- [ ] No paid/destructive action without human approval.
