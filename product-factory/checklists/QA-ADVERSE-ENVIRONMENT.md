# QA — Adverse Environment

- [ ] Slow network and retry behavior.
- [ ] API/database unavailable.
- [ ] Expired session.
- [ ] Partial data and empty state.
- [ ] Duplicate submit/concurrent action.
- [ ] Browser refresh/direct URL/404 fallback.
- [ ] Mobile, desktop and narrow viewport.
- [ ] Error does not expose secret/PII or leave invalid state.
