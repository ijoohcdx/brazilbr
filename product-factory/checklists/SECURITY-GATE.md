# Security Gate

- [ ] Auth providers/domains reviewed.
- [ ] Authorization enforced server-side/database-side.
- [ ] Private/public/admin data classified.
- [ ] No allow-all rule, service key or secret in client.
- [ ] Env names and build exposure reviewed.
- [ ] XSS, injection, CSRF where applicable, uploads and external URLs reviewed.
- [ ] User isolation, ID spoofing and query/Rules compatibility tested.
- [ ] Rate limiting and abuse controls assessed.
- [ ] Critical = immediate block; High = block unless approved exception.
